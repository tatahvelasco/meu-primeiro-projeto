# Meu Primeiro Projeto Node.js

![Status dos testes](https://github.com//tatahvelasco/meu-primeiro-projeto/actions/workflows/test.yml/badge.svg)

Este repositório foi criado como parte da minha jornada no programa **Azure Frontier Girls**, uma iniciativa da Microsoft em parceria com a WoMakersCode para formar mulheres líderes na Era da Inteligência Artificial. 💙

## Sobre o Projeto

Este é meu primeiro projeto Node.js versionado com Git e hospedado no GitHub. Ele faz parte do [roteiro oficial de estudos](https://github.com/AZFRONTIERGIRLS/AZFrontierGirls-Duvidas/discussions/26) do curso e tem como objetivo aplicar na prática os conceitos de versionamento, automação com GitHub Actions e testes automatizados com Jest.

## Funcionalidades

- Função `multiply(a, b)` que retorna o produto de dois números
- Testes automatizados com **Jest**
- Pipeline de integração contínua com **GitHub Actions**

## Como executar os testes

```bash
npm install
npm test
```
## Tecnologias utilizadas

## Sobre o Azure Frontier Girls

O Azure Frontier Girls é um programa de mentoria da Microsoft que prepara mulheres para liderar na Era Agentic, com foco em IA, copilots e arquiteturas multiagente no Azure. São 8 semanas de aulas ao vivo, mentorias técnicas, trilhas práticas e um showcase final com projetos incríveis.
